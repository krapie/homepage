# Homepage

Personal homepage for Kevin Park — a minimal link-in-bio page with profile links, an app gallery, and a brief intro. Built with Vite + React and the kevinprk design system. **Live:** [kevinprk.com](https://kevinprk.com)

## Getting Started

```bash
npm install
npm run dev   # http://localhost:5173
```

## Features

- **Profile links** — animated cards linking to GitHub, LinkedIn, and other social profiles; hover reveals a subtle lift effect
- **App gallery** — curated list of all public apps on kevinprk.com with a short description of each
- **Design system** — follows the kevinprk design system: neutral palette, Inter + JetBrains Mono, π mark in the header, no gradients or decorative flourishes
- **Dark mode** — respects the system preference by default; manual toggle in the header for overriding
